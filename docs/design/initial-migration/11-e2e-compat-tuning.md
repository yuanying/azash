# 11 E2E互換チューニング

## 目的

差分ハーネスを使ってJava版との差分を収束させ、実用互換の品質を固める。

## 成果物

- 回帰テストセット
- 差分優先度表
- 残差分の既知課題リスト

## チェックリスト

- [ ] `test_data` 一式をE2E対象に登録
- [ ] 差分優先度を定義 (本文構造 > 目次 > 見た目微差)
- [ ] 重大差分を修正して再比較
- [ ] 許容差分をドキュメント化
- [ ] リリース判定基準を文書化
- [ ] 継続回帰のCIジョブを追加

## 受け入れ条件

- 主要サンプルで「利用者視点で同等」と判断できる状態に到達する。
