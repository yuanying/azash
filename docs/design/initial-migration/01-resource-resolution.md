# 01 リソース解決層

## 目的

`template/`, `chuki_*.txt`, `replace*.txt`, `gaiji/`, `presets/`, `web/` を Java版と同等に解決する。

## 成果物

- リソース探索ポリシー仕様
- リソースローダ実装
- 解決結果を確認する自己診断コマンド/ログ

## チェックリスト

- [ ] 探索順序を定義 (CLI指定 > 実行ディレクトリ > 同梱パス > embed fallback)
- [ ] `template/` 読込実装
- [ ] `chuki_*.txt` / `replace*.txt` 読込実装
- [ ] `gaiji/` 読込実装
- [ ] `presets/` 読込実装
- [ ] `web/*/extract.txt` の読込可否確認 (初期は実行未使用でも可)
- [ ] 「欠落リソース時のエラーメッセージ」を統一
- [ ] 実行時に採用したリソースパスをログ出力

## 受け入れ条件

- Java版資産をそのまま配置してGo版が起動・変換できる。
