# 04 入力抽象化層

## 目的

txt/zip/txtz/rar/cbz を統一的に扱い、テキスト本体と画像情報を提供する。

## 成果物

- 入力Readerインタフェース
- archive実装 (zip/txtz/rar/cbz)
- 文字コード判定統合

## チェックリスト

- [ ] txt入力実装
- [ ] zip/txtzでtxtエントリ列挙と`txtIdx`選択を実装
- [ ] cbz/画像のみ判定を実装
- [ ] rar対応方針を明文化 (初期は限定対応/後続対応)
- [ ] `AUTO/MS932/UTF-8` 判定フローを実装
- [ ] 入力エラー時の復旧方針 (skip/abort) を定義
- [ ] サンプル入力に対するI/Oテストを作成

## 受け入れ条件

- Java版相当の入力種別で変換開始前処理が通る。
